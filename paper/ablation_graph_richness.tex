% ABLATION — Graph Richness on MAST (4-point sweep + null-graph control)
%
% Methodology paragraph (for inclusion in the paper body):
% --------------------------------------------------------
%
% \paragraph{Graph-richness ablation.}
% To isolate the contribution of edge-set richness from that of the
% injection architecture, we ablate the size of the causal graph
% supplied at inference time while holding every other component fixed.
% Beyond the \textsc{causal-only} graph (the 11 intervention-validated
% edges used in the main results), we sweep three correlation
% thresholds $\tau\in\{0.60,\,0.50,\,0.40\}$ that admit increasingly
% rich subsets of the Suppes candidate pool, and a null-graph
% \textsc{random-11} control that samples 11 directed edges uniformly
% from the 13-category MAST taxonomy excluding all Suppes-screened
% pairs (seed fixed at 42).
% Each candidate edge $A\!\to\!B$ in the Suppes pool receives a
% \emph{geometric-mean score}
% $\mathrm{score}(A\!\to\!B)=\sqrt{P(A\text{ precedes }B\mid \text{both})\;\cdot\;\Delta_{\mathrm{PR}}(A\!\to\!B)}$,
% where the first factor is the empirical temporal-precedence rate and
% $\Delta_{\mathrm{PR}}(A\!\to\!B)=P(B\mid A)-P(B\mid \neg A)$ is the
% Suppes probability-raising signal. These are the two graded Suppes
% statistics used to admit edges in the screening stage, and they are
% independent (precedence is computed only on traces where both $A$
% and $B$ occur, while $\Delta_{\mathrm{PR}}$ contrasts $B$'s rate
% under presence vs.\ absence of $A$). Both factors lie in $[0,1]$,
% so the geometric mean is monotone in each and penalises edges that
% are strong on only one criterion. At each $\tau$ the
% corr~$\geq\tau$ edge set is the union of (i) all Suppes edges with
% geomean $\geq\tau$ and (ii) the 11 intervention-validated causal
% edges (kept regardless of geomean so that no main-result edge is
% dropped by the threshold filter). The three points yield edge-set
% sizes $\{18,25,29\}$, anchored against \textsc{causal-only} ($11$)
% and \textsc{random-11} ($11$, null-graph control).
% We hold the threshold and edge set fixed across models and
% evaluate the two-pass dynamic injection variant (+GI) under each:
% Pass~1 detects errors with no graph and Pass~2 injects only the
% targeted subgraph rooted at the detected errors. The ablation is
% scoped to the open-source panel; closed-source GPT-4o is excluded
% so that the contrast cannot be confounded by API-side behaviour.
%
% --------------------------------------------------------
%
% Purpose: trace how W-F1 and Macro-F1 respond as the injected
% graph grows from 11 random edges (null control) to 29
% observationally-screened edges, with the intervention-validated
% causal-only graph (11 edges) as the inductive-bias anchor.
%
% Sources (N=393 AG2 traces per cell):
%   causal-only +GI : outputs_full/*-yesno-graph-inject-codename-causal_only-metrics.json
%                     (QwQ: outputs_think/QwQ-32B-yesno-graph-inject-codename-causal_only-thinking-metrics.json)
%   random-11   +GI : outputs_thres/t_random11_seed42/*-yesno-graph-inject-codename-random11_seed42-metrics.json
%   corr>=0.60  +GI : outputs_thres/t0.6/*-yesno-graph-inject-codename-corr0.6-metrics.json
%   corr>=0.50  +GI : outputs_thres/t0.5/*-yesno-graph-inject-codename-corr0.5-metrics.json
%   corr>=0.40  +GI : outputs_thres/t0.4/*-yesno-graph-inject-codename-corr0.4-metrics.json
%
% Edge sets (from suppes_graph.json + effect_edges.json):
%   random-11   : 11 random directed edges (seed 42)
%   causal-only : 11 intervention-validated edges
%   corr >=0.60 : 18 edges (causal-only union with geomean>=0.60)
%   corr >=0.50 : 25 edges
%   corr >=0.40 : 29 edges
%
% Scope: 5-model open-source panel (Mistral-Small-3.1-24B,
% GPT-oss-120B, GPT-oss-20B, Gemma-3-27B-IT, QwQ-32B with thinking
% enabled). All cells N=393. Closed-source GPT-4o excluded by design.
%

% Take-aways (for paper text reference; not part of the table):
%
% 1. Inductive bias (causal-only) vs. null-graph (random-11) at matched
%    edge count (11 vs 11). On the five-model panel, causal-only beats
%    random-11 on W-F1 in 4 of 5 models -- Mistral (37.01 vs 36.88),
%    GPT-oss-120B (25.26 vs 25.15), GPT-oss-20B (21.68 vs 21.05), and
%    Gemma (20.25 vs 16.95). QwQ-32B is the exception: random-11
%    (16.08) > causal-only (13.69) by 2.39 W-F1. On Macro-F1 the picture
%    is rougher -- causal-only wins on Mistral and Gemma; random-11
%    wins on GPT-oss-20B, GPT-oss-120B, and QwQ-32B. Net: causal edges
%    are the right inductive prior for most cells on the headline W-F1
%    metric, but the gap at matched edge count is small (<= 1 W-F1 on
%    Mistral / GPT-oss-120B / GPT-oss-20B) and Gemma is the only model
%    where causal-only convincingly outperforms the random control
%    (+3.30 W-F1).
%
% 2. Graph richness lifts W-F1 on the four non-QwQ models. Going from
%    11 causal edges to 29 corr>=0.40 edges yields:
%      Mistral       : 37.01 -> 38.29   (+1.28)
%      GPT-oss-120B  : 25.26 -> 27.95   (+2.69)
%      GPT-oss-20B   : 21.68 -> 20.76   (-0.92)   <-- regresses at saturating end
%      Gemma         : 20.25 -> 20.52   (+0.27)   <-- essentially flat
%      QwQ-32B       : 13.69 -> 16.01   (+2.32)
%    The corr>=0.40 (saturating) point is not uniformly the best:
%    GPT-oss-20B peaks at corr>=0.50 and then drops by corr>=0.40;
%    Gemma also peaks at corr>=0.50; QwQ peaks at random-11 then
%    monotonically approaches but never recovers it. The intermediate
%    corr>=0.50 (25 edges) point is the most consistent: all five
%    models improve from causal-only at this threshold
%    (Mistral +0.39, GPT-oss-120B +1.95, GPT-oss-20B +0.66, Gemma
%    +0.92, QwQ +1.92).
%
% 3. Best-threshold disagrees across (model, metric):
%      - W-F1 winners : corr>=0.40 (Mistral, GPT-oss-120B),
%                       corr>=0.50 (GPT-oss-20B, Gemma),
%                       random-11   (QwQ-32B).
%      - Macro-F1 winners : corr>=0.40 (Mistral, GPT-oss-120B),
%                           corr>=0.50 (Gemma),
%                           random-11  (GPT-oss-20B, QwQ-32B).
%    The corr>=0.60 (18 edges, "just above causal-only count") is
%    never the best for any (model, metric) cell. The headroom
%    unlocked by the first 7 added edges is small; most gains come
%    from doubling the edge set (corr>=0.50 with 25 edges).
%
% 4. Practical recommendation: corr>=0.50 (25 edges) is the most
%    defensible default for the +GI variant on MAST -- it improves
%    every model over causal-only on W-F1, peaks for two models
%    (GPT-oss-20B, Gemma), and is within 0.95 W-F1 of the
%    per-model optimum elsewhere (Mistral 37.40 vs 38.29 peak,
%    GPT-oss-120B 27.21 vs 27.95 peak, QwQ 15.61 vs 16.08 peak).
%
% 5. Cross-benchmark consistency. On TRAIL (open-source panel),
%    corr>=0.20 +GI+SI lifts W-F1 by +3.23 (Mistral GAIA),
%    +10.48 (GPT-oss-120B), +8.01 (GPT-oss-20B), and +8.63
%    (QwenLong); Gemma is the lone regressor (-4.18). On MAST the
%    +GI gains from causal-only -> saturating threshold are 2--10x
%    smaller (+1.28 / +2.69 / -0.92 / +0.27 / +2.32 across Mistral
%    / GPT-oss-120B / GPT-oss-20B / Gemma / QwQ). The directional
%    finding (+GI absorbs the larger graph without collapse) is
%    benchmark-independent; the magnitude is benchmark-dependent,
%    with TRAIL showing the larger headroom.
%
% 6. QwQ-32B is the only model where the null-graph control
%    (random-11) is the absolute best W-F1 and Macro-F1 cell. Across

%    randoms at 16.08), suggesting the +GI variant on QwQ is
