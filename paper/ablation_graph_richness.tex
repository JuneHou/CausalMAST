% Take-aways (for paper text reference; not part of the table):
%
% 1. +GI absorbs the larger graph uniformly across all 4 open-source
%    models (+1.87 to +7.53 W-F1). Same direction as the TRAIL
%    ablation: two-pass targeted injection scales gracefully with
%    graph size.
%
% 2. +CG behaves inconsistently with the larger graph:
%      Mistral  : -9.84 W-F1  (substantial regression)
%      GPT-120B : +2.00
%      GPT-20B  : +0.26 (essentially flat)
%      Gemma    : +0.53
%    Confirms that the one-pass static-graph variant does not scale
%    to richer edge sets. Important for the paper because Mistral
%    +CG (causal-only) is the headline winner of the MAST main
%    table at 47.31 W-F1 -- demonstrating that this peak is
%    fragile to graph expansion.
%
% 3. Cross-benchmark consistency: on TRAIL (open-source panel),
%    corr>=0.2 +GI+SI also wins on 3 of 4 models with comparable
%    magnitudes (Mistral +6.17, GPT-120B +6.30, GPT-20B +9.75 W-F1
%    on GAIA_dedup). The two-pass GI architecture's robustness to
%    graph richness is a benchmark-independent finding.
%
% 4. Gemma is the largest +GI gainer on MAST (+7.53), opposite to
%    its TRAIL behaviour (corr0.2 +GI+SI regresses by -4.31 on
%    GAIA_dedup). The TRAIL Gemma regression therefore appears to
%    be benchmark-specific (likely tied to specific TRAIL categories
%    that the +6 TRAIL edges activate), not a general "Gemma can't
%    handle bigger graphs" pattern.
%
% 5. Implication: on MAST, the canonical method choice should depend
%    on graph richness:
%      - Causal-only: +CG dominates (Mistral 47.31 vs +GI 37.01).
%      - Larger graph: +GI dominates (Mistral +GI 38.88 vs +CG 37.47).
%    The cleanest story for the paper is "+GI is robust across graph
%    sizes; +CG is best only with the small validated-edge set."
%
% 6. QwQ-32B (reasoning model, thinking enabled) follows the same
%    qualitative pattern as the other open-source models:
%      - +CG regresses with the larger graph (-2.91 W-F1, -1.66 Macro)
%      - +GI gains with the larger graph (+2.48 W-F1, +2.01 Macro)
